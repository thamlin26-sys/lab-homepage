# lab-homepage

Starter for the **Hello, Homepage** (week 1) and **Dress It Up** (week 2) labs
in *CSCI 40: Computing for the Web*. This same page becomes the seed of
Project 0.

Fork this repository, then:

1. **Week 1 (HTML):** build out `index.html` (fill in the `TODO`s), then run it
   through the [W3C validator](https://validator.w3.org/) until it reports
   *No errors or warnings to show.*
2. **Week 2 (CSS):** add rules to `style.css`, then publish the page with
   **GitHub Pages** (Settings -> Pages -> deploy from your default branch) and
   validate the CSS at <https://jigsaw.w3.org/css-validator/>.

These are graded on what you produce (the page + a validator screenshot in
week 1; the live GitHub Pages URL in week 2), so there is no test badge here.
